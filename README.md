# Gabriel Fernandes

Desenvolvedor Full Stack e Mobile. Construo produtos mobile e web completos: app, backend e infraestrutura em nuvem, da especificação à publicação na loja.

Na Kavicki, fui o único desenvolvedor de três produtos de clientes, responsável por arquitetura, modelo de dados, pagamentos, infraestrutura e publicações. Entre eles, um marketplace com pagamentos reais publicado na App Store e uma plataforma que trata dados de saúde sob a LGPD, entregue e aprovada pelo cliente.

**Stack:** TypeScript · React Native / Expo · React · Node.js (Fastify, NestJS) · PostgreSQL (Prisma) · Supabase · AWS (CDK, Lightsail, Cognito, Lambda, S3, SQS) · Pagamentos (Mercado Pago, Stripe) · Swift e Kotlin (módulos nativos) · Jest / Vitest
